# Scanner Check Catalogue

Implemented checks include HTTPS use, TLS certificate handshake, negotiated TLS version, HSTS/CSP/X-Content-Type-Options/Referrer-Policy/Permissions-Policy/frame protections, cookie Secure/HttpOnly/SameSite attributes, technology banner exposure, CORS coarse policy review, mixed content, secure form actions, password forms using GET, CSRF-token heuristic and developer-comment disclosure.

The catalogue intentionally prioritizes repeatable, explainable and non-destructive tests. Automated findings are mapped to relevant WSTG/ASVS areas where appropriate; mapping does **not** imply full compliance coverage.
